# STAFF A.12.1-R1 — Istruzioni

1. Conservare il proprio file `.env`.
2. Sostituire la cartella NZ con quella contenuta nello ZIP.
3. Ripristinare `.env` nella radice di NZ.
4. Eseguire `npm install`.
5. Eseguire `npm run check`.
6. Eseguire `npm run dev`.
7. Aprire un Match Report e verificare l'anteprima di stampa.
8. In Chrome disattivare “Intestazioni e piè di pagina” e attivare “Grafica in background”.
9. Salvare come PDF e controllare che testo, campi e campi da calcio siano visibili.

Nessun SQL richiesto.
