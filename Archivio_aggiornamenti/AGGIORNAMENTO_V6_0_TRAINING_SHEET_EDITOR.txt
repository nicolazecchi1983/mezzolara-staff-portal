NZ V6.0 — TRAINING SHEET EDITOR BASE

COSA INCLUDE
- Nuova voce di menu "Training Sheet"
- Area per incollare la dettatura
- Parser locale iniziale
- Campi strutturati e modificabili
- Controllo campi mancanti
- Calcolo durata totale
- Salvataggio bozza su Supabase
- Nessuna generazione PDF in questa release
- Nessuna registrazione vocale in questa release

ORDINE OPERATIVO
1. Eseguire SUPABASE_TRAINING_SHEET_EDITOR_V6.sql su Supabase.
2. Sostituire il progetto locale con i file di questo pacchetto.
3. Aprire il terminale nella cartella NZ.
4. Eseguire: npm install
5. Eseguire: npm run dev
6. Aprire il portale, entrare come amministratore e scegliere Training Sheet.
7. Incollare la dettatura del 30 luglio e premere Analizza seduta.
8. Verificare i campi e premere Salva bozza.
9. Solo dopo il test eseguire commit e push.
