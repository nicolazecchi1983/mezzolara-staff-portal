# STAFF — A.11.3 + A.12

## Installazione
1. Sostituire la cartella locale `NZ` con il contenuto dello ZIP, mantenendo al sicuro il proprio `.env`.
2. Aprire il terminale nella cartella `NZ`.
3. Eseguire `npm install`.
4. Eseguire `npm run dev` e verificare la nuova voce `Match Library`.
5. Non è necessario eseguire SQL su Supabase.

## Test rapido
- Aprire Match Library e verificare le partite del Calendario.
- Creare una nuova gara manuale.
- Provare ricerca e filtri.
- Aprire il Match Sheet dalla gara.
- Verificare la stampa del Match Report e delle convocazioni.
- Eseguire `npm run build` sul PC locale.
